## Steps: breaking down a reel Nick sends
1. Download, transcribe (faster-whisper), 14-frame contact sheet; note likes/comments, creator's median views.
2. Write the breakdown: hook (visual / spoken / text), the question it opens, lock-in, rehooks, payoff, CTA, edit
   style (what changes every 2-3 s), length, why it worked (label fact vs inferred).
3. The plumbing version: keep the FORMAT, change the topic to a plumbing owner's problem (calls, jobs, money, Google).
   Name the source for the caption credit.
4. Add it to the ideas bank `rules/content-ops/ideas-bank.md` (date, source link, format, plumbing angle, status).
5. Check before done: the re-make passes the plan s3 checklist; no footage of the source reel is reused without
   Nick's OK (reach and copyright risk).

## Steps: creator study
Grid views (median, top, bottom), transcribe top and bottom reels, compare what hits vs flops, update the notes
file for that creator with dates. Never claim a number not seen.
